# DocuMind 🧠

**Chat with your PDFs.** DocuMind is a full-stack Retrieval-Augmented Generation (RAG) application — upload documents, ask questions in natural language, and get answers grounded in your own files with page-level citations.

## ✨ Features

- 🔐 **Full authentication** — signup, login, JWT access + refresh tokens, argon2 password hashing, server-side token revocation
- 📄 **PDF ingestion** — upload via API or dashboard; PyMuPDF extracts page-wise text
- 🧩 **Smart chunking** — `RecursiveCharacterTextSplitter` with overlap and position tracking
- 🧠 **Local embeddings** — `mxbai-embed-large` via Ollama, no external API keys needed
- 🔎 **Semantic search** — ChromaDB vector retrieval filtered per user and per document
- 💬 **Grounded Q&A** — answers generated by a local LLM (`qwen2.5-coder:7b`) using only retrieved context, with prompt-injection guardrails
- 📚 **Source citations** — every answer links back to the page and chunk it came from
- 🗂️ **Document management** — list your uploaded documents with page/chunk counts
- 🖥️ **Web dashboard** — Next.js 16 frontend with auto token-refresh on expiry

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| **Backend** | Python, FastAPI, SQLAlchemy, Alembic |
| **Database** | MySQL — users, documents, refresh tokens |
| **Vector store** | ChromaDB (persistent, local) |
| **LLM / Embeddings** | Ollama — `mxbai-embed-large` (embeddings), `qwen2.5-coder:7b` (chat) |
| **RAG framework** | LangChain (`langchain_ollama`, `langchain_chroma`, `langchain_text_splitters`) |
| **Auth** | JWT (`python-jose`), argon2 (`passlib`) |
| **Frontend** | Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4 |
| **PDF** | PyMuPDF |

## 🏗️ Architecture

### RAG pipeline

```text
PDF Upload
   │
   ▼
Text Extraction (PyMuPDF, page-wise)
   │
   ▼
Recursive Chunking (1000 chars, 150 overlap)
   │
   ▼
Embedding Generation (Ollama · mxbai-embed-large)
   │
   ▼
Persistent Vector Storage (ChromaDB)
   metadata: { page, start_index, source_id, user_id }
   │
   ▼
Question ──► Semantic Retrieval (k-NN, filtered by user_id)
   │
   ▼
Prompt + Guardrails ──► LLM (Ollama · qwen2.5-coder:7b)
   │
   ▼
Answer + Source Citations
```

## 🚀 Getting Started

### Prerequisites

- Python 3.11+
- Node.js 20+
- MySQL 8
- [Ollama](https://ollama.com/) installed and running
- Git

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/DocuMind.git
cd DocuMind
```

### 2. Backend setup

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\Activate.ps1
pip install -r requirements.txt

cp .env.example .env
```

Configure `.env`:

```env
DATABASE_URL=mysql+pymysql://documind_user:your_password@localhost:3306/documind
SECRET_KEY=generate-a-long-random-string
```

Generate a secret key:

```bash
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

Create the MySQL database and user (see [SETUP_AUTH.md](SETUP_AUTH.md) for detailed instructions), then run migrations:

```bash
cd app
alembic upgrade head
```

### 3. Pull the Ollama models

```bash
ollama pull mxbai-embed-large
ollama pull qwen2.5-coder:7b
```

### 4. Start the backend

```bash
cd app
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

- API: `http://localhost:8000`
- Swagger docs: `http://localhost:8000/docs`

### 5. Start the frontend

```bash
cd frontend
npm install
echo "NEXT_PUBLIC_API_URL=http://localhost:8000" > .env.local
npm run dev
```

Open `http://localhost:3000` → sign up → upload a PDF → ask questions.

## 🔒 Security

- Passwords hashed with **argon2** — never stored or logged in plaintext
- `SECRET_KEY` is **required** via environment variable; the app refuses to start without it
- Access tokens expire in **30 minutes**; refresh tokens in **7 days** and are revocable
- All document endpoints require a valid Bearer token and filter results by `user_id`
- Vector metadata enforces per-user retrieval isolation
- CORS restricted to the frontend origin
- The LLM system prompt instructs the model to treat document content as data, not instructions (basic prompt-injection mitigation)

## 🚢 Deployment

DocuMind runs fully self-hosted: FastAPI + MySQL + Ollama + ChromaDB on the backend, Next.js on the frontend.

**Recommended approach — single VPS with Docker Compose:**

- `api` — FastAPI container
- `frontend` — Next.js container (`output: "standalone"`)
- `mysql` — MySQL 8
- `ollama` — Ollama + pre-pulled models
- Named volume for `chroma_langchain_db` persistence
- Caddy/nginx for HTTPS

**Alternative — managed PaaS:** deploy the frontend to Vercel and the backend to Render/Railway, but note that Ollama and persistent ChromaDB don't run on standard serverless platforms — you'd need to swap in hosted embeddings/LLM APIs and a managed vector DB.

## ⚠️ Known Limitations

- Scanned PDFs without a text layer aren't supported (no OCR)
- No document deletion or re-indexing yet
- No rate limiting on auth endpoints
- Access tokens stored in `localStorage` (fine for demo; httpOnly cookies preferred for production)
- Built for development/demo — not hardened for production
